## Overview:
This script simulates a stateless frontend for RankPilot, interacting with a backend API via HTTP POST requests. It handles PDF file uploads, base64 encoding, and an iterative process of answering questions posed by the backend to resolve "gaps" in a submission. The simulation mimics the data structures and interaction patterns expected from a Laravel-style backend.

There are no explicit classes defined in this script.

| `main` | `filepath` (from command-line arguments) | Parses command-line arguments to get the PDF filepath. Validates file existence. Reads and base64 encodes the file. Constructs an initial `agent_state` dictionary. Makes an initial HTTP POST request to the `API_URL` (`http://localhost:8000/process`) with the file and initial state. Enters a loop to process backend responses: prints backend logs, checks for "gaps". If gaps exist and a "question_text" is present in `new_answer`, it prompts the user for an answer, mocks it if empty, updates the `agent_state` with the answer, and sends another HTTP POST request. The loop continues until no gaps are found or a maximum iteration count is reached. Finally, it prints the assembled document (if available) and the final submission data, censoring sensitive base64 information. Handles `requests.exceptions.ConnectionError` and non-200 status codes. |
