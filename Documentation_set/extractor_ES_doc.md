## Resumen:
Este archivo define la función `ingestion_node`, que es responsable de procesar el texto extraído de los documentos. Utiliza una fábrica centralizada (`get_schema_class`) para determinar el esquema de datos apropiado basado en el `target_submission_type`. Luego, la función intenta estructurar el texto extraído en este esquema utilizando un LLM de Langchain, con un mecanismo robusto de manejo de errores y una alternativa a un esquema vacío si la extracción falla. También maneja la inyección de metadatos en los datos estructurados.
