1. ## Overview:
This file contains logic for processing user answers within an agentic workflow, specifically focusing on extracting structured data, handling user intents, and updating a submission object. It determines whether a user's response should fill a field, be dismissed, or requires clarification.

2. ## Classes:
*   `AnswerIntent`: Pydantic model to represent the AI's classification of a user's answer, including the inferred action (fill, dismiss, clarify) and any extracted value.
