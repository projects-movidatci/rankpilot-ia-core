## Resumen:
Este archivo proporciona funciones de utilidad para codificar archivos en cadenas Base64.

## Clases:

## Funciones y Métodos:
| Nombre | Parámetros | Responsabilidad |
|---|---|---|
| `encode_file_to_base64` | `filepath`: str | Lee un archivo desde la ruta de archivo proporcionada, codifica su contenido binario en una cadena Base64 y la devuelve. Devuelve `None` si el archivo no se encuentra o si ocurre un error durante la codificación. |
