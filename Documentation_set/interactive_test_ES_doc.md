## Resumen:
Este script simula un frontend sin estado para RankPilot, interactuando con una API backend a través de solicitudes HTTP POST. Maneja la carga de archivos PDF, la codificación base64 y un proceso iterativo para responder a las preguntas planteadas por el backend para resolver "lagunas" en una presentación. La simulación imita las estructuras de datos y los patrones de interacción esperados de un backend estilo Laravel.

## Clases:
No hay clases explícitas definidas en este script.

| `main` | `filepath` (argumentos de línea de comandos) | Analiza los argumentos de línea de comandos para obtener la ruta del archivo PDF. Valida la existencia del archivo. Lee y codifica el archivo en base64. Construye un diccionario `agent_state` inicial. Realiza una solicitud HTTP POST inicial a la `API_URL` (`http://localhost:8000/process`) con el archivo y el estado inicial. Entra en un bucle para procesar las respuestas del backend: imprime los registros del backend, verifica si hay "lagunas". Si existen lagunas y hay un "question_text" presente en `new_answer`, solicita al usuario una respuesta, la simula si está vacía, actualiza el `agent_state` con la respuesta y envía otra solicitud HTTP POST. El bucle continúa hasta que no se encuentren lagunas o se alcance un número máximo de iteraciones. Finalmente, imprime el documento ensamblado (si está disponible) y los datos de la presentación final, censurando la información sensible base64. Maneja las excepciones `requests.exceptions.ConnectionError` y los códigos de estado no 200. |
