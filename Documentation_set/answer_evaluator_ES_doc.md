1. ## Visión general:
Este archivo contiene la lógica para procesar las respuestas del usuario dentro de un flujo de trabajo de agente (agentic workflow), centrándose específicamente en la extracción de datos estructurados, el manejo de intenciones del usuario y la actualización de un objeto de envío (submission object). Determina si la respuesta de un usuario debe completar un campo, ser descartada o requiere aclaración.

2. ## Clases:
*   `AnswerIntent`: Modelo Pydantic para representar la clasificación de la IA de la respuesta de un usuario, incluyendo la acción inferida (rellenar, descartar, aclarar) y cualquier valor extraído.

3. ## Funciones y Métodos:

| Nombre                       | Parámetros                                  | Responsabilidad                                                                                                                                                                                                                                                   |
| :------------------------- | :------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `update_nested_field`      | `data`, `target`, `new_value`               | Actualiza recursivamente un campo anidado dentro de una estructura de diccionario o lista basándose en una ruta `target` de notación de puntos. Maneja la creación de diccionarios o listas intermedias si no existen.                                           |
| `process_answer_node`      | `state: AgentState`                         | La función principal para procesar el `new_answer` del usuario desde el estado del agente. Analiza la respuesta usando un LLM, determina la intención (rellenar, descartar, aclarar), actualiza los campos descartados (dismissed gaps), el historial e inyecta los datos completados en el objeto `submission`. |
