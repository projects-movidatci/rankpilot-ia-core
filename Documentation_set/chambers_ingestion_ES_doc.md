1. ## Resumen:
Este archivo contiene una función de nodo responsable de ingerir y estructurar datos de un documento de envío de Chambers. Aprovecha un LLM para extraer información específica, centrándose particularmente en el manejo de datos de tablas potencialmente mal formadas y detalles de contacto dentro de documentos legales.

2. ## Clases:
- `AgentState`: Representa el estado general del agente, probablemente conteniendo información como texto extraído, el paso actual y mensajes.
- `ChatOpenAI`: Una clase de la biblioteca `langchain_openai` para interactuar con los modelos de chat de OpenAI.
- `ChatPromptTemplate`: Una clase de `langchain_core.prompts` para definir plantillas de prompts para modelos de chat.
- `ChambersSubmission`: Un esquema Pydantic diseñado para contener la salida estructurada del proceso de ingesta de Chambers.

| `chambers_ingestion_node` | `state: AgentState`            | Actúa como un nodo de procesamiento para extraer y estructurar datos de un envío de Chambers. Primero recupera el texto sin procesar del estado del agente, verifica si el texto está vacío y se aborta con un mensaje de error si lo está. Luego inicializa un LLM con un prompt específico diseñado para manejar estructuras de tablas desordenadas y extraer puntos clave de datos legales como jefes de departamento, su información de contacto y resúmenes de departamentos. La función construye una cadena Langchain utilizando el prompt y un configurador de salida de LLM estructurado (utilizando el esquema `ChambersSubmission`). Invoca esta cadena con el texto sin procesar e intenta almacenar los datos estructurados extraídos en el estado del agente. Se incluye manejo de errores para capturar excepciones durante la interacción con el LLM y registrarlas en los mensajes del estado. La función devuelve un diccionario que contiene las actualizaciones al estado del agente, incluido el paso actual, cualquier mensaje generado y los datos de `submission` extraídos.
