## Overview:
This file defines the `ingestion_node` function, which is responsible for processing extracted text from documents. It uses a centralized factory (`get_schema_class`) to determine the appropriate data schema based on the `target_submission_type`. The function then attempts to structure the extracted text into this schema using a Langchain LLM, with a robust error handling mechanism and a fallback to an empty schema if extraction fails. It also handles injecting metadata into the structured data.
